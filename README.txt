รุ่นรายการ 1.64.1-commands.5 — CHABA Menu Studio
- เมนูใหม่สีถ่าน/มิ้นต์ สวิตช์เคลื่อนไหว และกลุ่มพับได้
- เปิด/ปิดด้วย 3 นิ้วแตะจอ 2 ครั้ง ไม่มีปุ่มลอย
- ปุ่ม × ปิดหน้าต่าง แล้วใช้ท่าทางเดิมเปิดกลับ
- ลากแถบชื่อเพื่อย้าย ปรับขนาดและความทึบใน SETTING
- ระบบคีย์และฟังก์ชันเกมเดิมคงไว้ ใช้ RoV resources 1.64.1

ติดตั้งอัปเดต:
1. 3105 > Sources > Refresh > CHABA Menu 1.64.1 > Download/Install
2. ปิด RoV ให้สนิท แล้ว Restore แพตช์ที่ใช้อยู่ก่อน Apply ชุดใหม่
3. เปิดเกม ตรวจคีย์และกดตกลงตามเดิม แล้วใช้ 3 นิ้วแตะจอ 2 ครั้งเปิดเมนู
Refresh Source อัปเดตรายการ แต่ไม่ Apply เกมให้อัตโนมัติ
